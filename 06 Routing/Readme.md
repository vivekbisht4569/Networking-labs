# Routing Lab 🌐

A practical Cisco Packet Tracer lab focused on understanding and configuring **network routing**.

## 📌 Topics Covered

* Routing Fundamentals
* IP Addressing
* Default Gateway
* Static Routing
* Routing Tables
* Next-Hop Routing
* Router Interface Configuration
* Connectivity Testing
* Routing Troubleshooting

## 🛠️ Tools Used

* Cisco Packet Tracer
* Cisco IOS CLI

## ⚙️ Commands Practiced

```bash
show ip interface brief
show ip route
show running-config
ping
traceroute
ip route
```

## 🎯 Objective

To understand how routers forward packets between different networks and gain practical experience configuring and troubleshooting routing in a simulated network environment.

## 🧪 Lab Work

The lab includes:

* Configuring router interfaces
* Assigning IP addresses
* Connecting multiple networks
* Configuring static routes
* Verifying routing tables
* Testing end-to-end connectivity
* Troubleshooting routing issues
